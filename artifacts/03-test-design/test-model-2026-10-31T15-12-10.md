- **requirement_id:** REQ-2.2

### TC-N-013 — Превышение лимита попыток (Rate Limiting)
- **Тип:** Negative
- **Приоритет:** High
- **Предусловия:** Пользователь на странице авторизации
- **Шаги:**
  1. Ввести неверные данные N раз (N = лимит попыток)
  2. На N+1 раз ввести корректные данные
- **Ожидаемый результат:** После N неудачных попыток включается CAPTCHA или временная блокировка. Даже корректные данные не принимаются до прохождения CAPTCHA/окончания блокировки.
- **requirement_id:** REQ-3

  3. Нажать «Войти»

- **requirement_id:** REQ-2.1, REQ-3

### TC-N-015 — CSRF-атака (отсутствие/невалидный токен)
- **Тип:** Negative
- **Приоритет:** High
- **Предусловия:** Злоумышленник пытается отправить форму с поддельным запросом
- **Шаги:**

- **requirement_id:** REQ-4.1

### TC-N-016 — Отправка пароля через GET
- **Тип:** Negative
- **Приоритет:** High
- **Предусловия:** — 
- **Шаги:**
  1. Попытаться отправить данные авторизации через GET-запрос (с параметрами в URL)
- **Ожидаемый результат:** GET-запрос отклонён. Данные принимаются только через POST.
- **requirement_id:** REQ-4.1

## 3. Boundary

### TC-B-001 — Поле «Логин»: 1 символ (нижняя граница)
- **Тип:** Boundary
- **Приоритет:** Medium
- **Предусловия:** Пользователь на странице авторизации
- **Шаги:**
  1. Ввести в поле «Логин» 1 символ (невалидный Email)
  2. Ввести пароль
  3. Нажать «Войти»
- **Ожидаемый результат:** Если поле принимает только Email — ошибка валидации формата. Если принимает Username — анализ по бизнес-правилам.
- **requirement_id:** REQ-2.1

### TC-B-002 — Поле «Логин»: 255 символов (верхняя граница)
- **Тип:** Boundary
- **Приоритет:** Medium
- **Предусловия:** Пользователь на странице авторизации
- **Шаги:**
  1. Ввести в поле «Логин» 255 символов
  2. Ввести пароль
  3. Нажать «Войти»
- **Ожидаемый результат:** Значение принимается (не более 255). При корректном Email и пароле — успешный вход.
- **requirement_id:** REQ-2.1

### TC-B-003 — Поле «Логин»: 256 символов (сверх границы)
- **Тип:** Boundary
- **Приоритет:** Medium
- **Предусловия:** Пользователь на странице авторизации
- **Шаги:**
  1. Попытаться ввести 256 символов в поле «Логин»
- **Ожидаемый результат:** Поле не принимает более 255 символов (обрезается или блокируется ввод). При вставке — ошибка валидации.
- **requirement_id:** REQ-2.1

### TC-B-004 — Поле «Пароль»: 7 символов (ниже min)
- **Тип:** Boundary
- **Приоритет:** Medium
- **Предусловия:** Пользователь на странице авторизации
- **Шаги:**
  1. Ввести корректный логин
  2. Ввести пароль из 7 символов
  3. Нажать «Войти»
- **Ожидаемый результат:** Ошибка валидации «Пароль слишком короткий». Минимальная длина — 8 символов.
- **requirement_id:** REQ-2.1

### TC-B-005 — Поле «Пароль»: 8 символов (min)
- **Тип:** Boundary
- **Приоритет:** Medium
- **Предусловия:** Пользователь зарегистрирован с паролем из 8 символов
- **Шаги:**
  1. Ввести корректный логин
  2. Ввести пароль из 8 символов
  3. Нажать «Войти»
- **Ожидаемый результат:** Пароль принят. При корректных данных — успешный вход.
- **requirement_id:** REQ-2.1

### TC-B-006 — Поле «Пароль»: 64 символа (max)
- **Тип:** Boundary

- **Предусловия:** Пользователь зарегистрирован с паролем из 64 символов

### TC-B-007 — Поле «Пароль»: 65 символов (сверх max)
