Ошибка **не** связана с выбором трекера/приоритета/проекта (проверено на двух проектах и минимальном пейлоаде) и **не** является транзитной (ретрай дал тот же результат).

**Действия по скиллу.** §7 Constraint («При недоступности Redmine → вернуть `INCOMPLETE` с `REDMINE_CONTEXT_MISSING`»), §10 Failure Behaviour («Ошибка API при создании кейса → лог, остановка, эскалация»), §11 Escalation («ошибка авторизации 401/403 при создании кейсов») → запись остановлена, эскалация Оркестратору, лог: `artifacts/errors/redmine-permission-20261110-202304.md`.
