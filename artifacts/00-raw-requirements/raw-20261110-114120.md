# Требования к странице регистрации

1. Форма регистрации
Поля: "Имя" (текст), "Email" (текст), "Пароль" (текст).
Поле "Имя" обязательно для заполнения.
Email должен быть уникальным в системе.

2. Кнопка "Зарегистрироваться"
При нажатии данные отправляются на сервер. При успехе пользователь видит сообщение "Регистрация успешна" и перенаправляется на главную страницу.

3. Производительность
Страница регистрации должна загружаться очень быстро и работать стабильно даже при высокой нагрузке.

# Acceptance Criteria (Критерии приемки)

- Given пользователь заполнил все поля валидными данными, When он нажимает "Зарегистрироваться", Then появляется сообщение "Регистрация успешна" и происходит редирект.
- Given пользователь ввел email, который уже есть в базе, When он нажимает "Зарегистрироваться", Then появляется ошибка "Этот email уже занят".
- Given пользователь оставил поле "Имя" пустым, When он нажимает "Зарегистрироваться", Then кнопка не срабатывает и появляется ошибка "Имя обязательно".
