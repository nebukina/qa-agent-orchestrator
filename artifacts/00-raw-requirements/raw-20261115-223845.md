# Требования к странице авторизации

1. Форма входа
На странице должны быть два поля: "Email" и "Пароль".

2. Валидация пароля
Пароль должен содержать не менее 6 символов.
Пароль должен содержать не менее 8 символов.

3. Кнопка "Войти"
При нажатии на кнопку "Войти" форма отправляет POST-запрос на /api/login.
Если сервер возвращает HTTP 200 OK, происходит перенаправление на /dashboard.
Если сервер возвращает HTTP 401 Unauthorized, появляется сообщение "Неверный email или пароль".

# Acceptance Criteria (Критерии приемки)

- AC-1: Given пользователь ввел пароль из 6 символов, When он нажимает "Войти", Then вход выполняется успешно.
- AC-2: Given пользователь ввел пароль из 8 символов, When он нажимает "Войти", Then вход выполняется успешно.
- AC-3: Given пользователь ввел неверный пароль, When он нажимает "Войти", Then появляется сообщение "Неверный email или пароль".
