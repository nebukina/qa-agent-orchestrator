Описание (дословно):

```
# Требования к странице регистрации

1. Форма регистрации
На странице должны быть три поля: "Имя" (текст), "Email" (текст) и "Пароль" (тип password, символы скрыты звездочками).
Поле "Имя" обязательно для заполнения.
Email должен быть уникальным в системе (проверка происходит на сервере).
Пароль должен содержать не менее 8 символов.

2. Кнопка "Зарегистрироваться"
При нажатии на кнопку данные отправляются POST-запросом на /api/register.
Если сервер возвращает 200 OK, пользователь видит сообщение "Регистрация успешна" и перенаправляется на страницу /dashboard.
Если сервер возвращает 409 Conflict (email уже занят), появляется ошибка "Этот email уже занят".
Если сервер возвращает 400 Bad Request (невалидные данные), появляется ошибка "Проверьте правильность заполнения полей".

3. Дизайн
Кнопка регистрации должна быть синего цвета.

# Acceptance Criteria (Критерии приемки)

- Given пользователь заполнил все поля валидными данными, When он нажимает "Зарегистрироваться", Then появляется сообщение "Регистрация успешна" и происходит редирект на /dashboard.
- Given пользователь ввел email, который уже есть в базе, When он нажимает "Зарегистрироваться", Then появляется ошибка "Этот email уже занят".
- Given пользователь оставил поле "Имя" пустым, When он нажимает "Зарегистрироваться", Then появляется ошибка "Проверьте правильность заполнения полей".
- Given пользователь ввел пароль короче 8 символов, When он нажимает "Зарегистрироваться", Then появляется ошибка "Проверьте правильность заполнения полей".
```
