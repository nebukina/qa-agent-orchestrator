Описание (дословно):

```
# Требования к странице авторизации (Вход)

1. Форма входа
На странице должны быть два поля: "Email" и "Пароль".
Поле "Email" должно иметь тип `email` (нативная HTML5 валидация).
Поле "Пароль" должно иметь тип `password`.
Оба поля обязательны для заполнения (атрибут required).

2. Кнопка "Войти"
При нажатии на кнопку "Войти" форма отправляет POST-запрос на эндпоинт `/api/login`.
Если сервер возвращает HTTP 200 OK, происходит перенаправление на страницу `/dashboard`.
Если сервер возвращает HTTP 401 Unauthorized, появляется сообщение об ошибке красного цвета: "Неверный email или пароль".

# Acceptance Criteria (Критерии приемки)

- AC-1: Given пользователь находится на странице входа, When он кликает на поле "Email", Then поле получает фокус ввода.
- AC-2: Given поле "Email" пустое, When пользователь нажимает "Войти", Then браузер показывает системную подсказку "Заполните это поле" (required).
- AC-3: Given пользователь ввел валидный email и верный пароль, When он нажимает "Войти", Then происходит перенаправление на `/dashboard`.
- AC-4: Given пользователь ввел валидный email и неверный пароль, When он нажимает "Войти", Then появляется красный текст "Неверный email или пароль".
```
