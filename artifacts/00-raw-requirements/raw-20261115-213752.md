# Требования к полю "Пароль"

1. Поле ввода
На странице должно быть поле "Пароль" типа password.
Пароль должен содержать от 8 до 64 символов включительно.

2. Валидация
Если длина пароля меньше 8 символов, появляется ошибка: "Пароль слишком короткий".
Если длина пароля больше 64 символов, появляется ошибка: "Пароль слишком длинный".
Если длина пароля от 8 до 64 символов, ошибка не появляется.

# Acceptance Criteria (Критерии приемки)

- AC-1: Given пользователь ввел пароль из 7 символов, When он убирает фокус с поля, Then появляется ошибка "Пароль слишком короткий".
- AC-2: Given пользователь ввел пароль из 8 символов, When он убирает фокус с поля, Then ошибка НЕ появляется.
- AC-3: Given пользователь ввел пароль из 64 символов, When он убирает фокус с поля, Then ошибка НЕ появляется.
- AC-4: Given пользователь ввел пароль из 65 символов, When он убирает фокус с поля, Then появляется ошибка "Пароль слишком длинный".
