### 1.2 Причина INCOMPLETE (детерминированный отказ записи)

`tools.redmine.create_issue` отклонён **5 раз** на разных payload'ах (включая минимальные `project_id`+`subject`, identifier и числовой id, со снятием `tracker_id`/`priority_id`) с идентичным текстом ошибки. Одновременно **все чтения работали штатно**, включая контрольное чтение, выполненное после последней неудачной попытки; `list_metadata(kind=me)` тоже отклонён → API-ключ **read-only**. Альтернативного инструмента записи в каталоге нет.

Согласно SKILL.md §7 / §10 / §11 (ошибка авторизации при создании задач) выполчены: лог ошибки, остановка записи, эскалация. **ID задач намеренно не выдуманы** — колонка Redmine ID оставлена пустой. Спецификация ниже готова к исполнению: повторный запуск `task` с write-ключом создаёт единицы «как есть», без переппроектирования.

> **Корректировка оркестратора (пост-фактум, 2026-11-10):** диагноз «ключ read-only» не подтвердился на прямом Redmine REST — под тем же ключом `POST /issues.json` возвращает 201. Отказ 403 генерировала MCP-обёртка redmine-инструментов. Все 15 единиц опубликованы оркестратором прямым REST (#73–#87) без изменения спецификации.
