# QA-Agent: Requirements-to-Delivery

Автоматизированный QA-агент-оркестратор, который проводит аудит требований из Confluence, проектирует спецификацию задач для Jira, формирует тестовую модель для Qase и собирает итоговый отчет с матрицей трассировки.


## Архитектура проекта

Проект построен на базе **OpenCode** и использует паттерн «Оркестратор + Скиллы».
1. **Оркестратор** (`qa-orchestrator`) управляет жизненным циклом задачи.
2. **Скиллы** (`skills/`) содержат изолированную бизнес-логику для каждого этапа (аудит, проектирование задач, проектирование тестов).


.
├── .opencode/
│   └── agents/
│       ├── qa-orchestrator.md # Главный агент (Оркестратор)
│       ├── task.md            # Субагент (вызывает только task-design)
│       └── test.md            # Субагент (вызывает только test-design)
├── skills/
│   ├── requirement-review/
│   │   └── SKILL.md           # Логика аудита требований (QG1)
│   ├── task-design/
│   │   └── SKILL.md           # Логика проектирования Jira (QG2)
│   └── test-design/
│       └── SKILL.md           # Логика проектирования Qase (QG3)
├── tools/
│   └── confluence.ts          # Утилита для работы с Confluence
├── artifacts/                 # Папка для сохранения результатов (создается автоматически)
├── AGENTS.md                  # Глобальные правила для всех агентов
├── opencode.json              # Конфигурация проекта OpenCode
└── README.md                  # Этот файл
